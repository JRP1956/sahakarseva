# Development guide

## Prerequisites (dev Mac as of Sept 2026)

| Tool | Version | Notes |
|---|---|---|
| Docker Desktop | 29+ | `open -a Docker` if the daemon isn't running |
| uv | any | manages Python 3.12 for `backend/` |
| Node | 22 | `admin/` |
| Flutter | 3.47 stable | `mobile/`; Chrome target works; Android needs `flutter doctor --android-licenses`; iOS needs Xcode + CocoaPods |
| libomp | brew | `brew install libomp` — required by XGBoost on macOS |

## First-time setup

```bash
git clone https://github.com/JRP1956/sahakarseva gig-work && cd gig-work
docker compose up -d db                       # PostGIS on localhost:5433 — creates dbs gig + gig_test with the extension
cd backend && uv sync && uv run alembic upgrade head && uv run python seed.py && cd ..
cd admin && npm install && cd ..
cd mobile && flutter pub get && flutter gen-l10n && cd ..
```

## Running everything

Three terminals (or the Claude browser pane `admin` launch config):

```bash
cd backend && uv run uvicorn app.main:app --reload --port 8000      # http://localhost:8000/docs
cd admin && npm run dev                                              # http://localhost:3000
cd mobile && flutter run -d chrome                                   # or -d web-server --web-port 5555
```

## Testing

```bash
cd backend && uv run pytest -q            # 22 tests; uses gig_test; each test rolls back
cd admin && npx next build                # type-checks and builds all routes
cd mobile && flutter analyze              # must report "No issues found"
```
There are no UI tests; walk `docs/DEMO-SCRIPT.md` in the browser after UI changes.

## Common tasks

### Add an API endpoint
1. Pick the router in `backend/app/routers/` (or add one and include it in `main.py`).
2. Put any rule in `backend/app/services/`, not the router.
3. Serialise with `routers/common.py` helpers if it returns a booking/worker.
4. Add a test in `backend/tests/` using `helpers.make_world` + `login`.
5. Document in `docs/API.md`.

### Add a column / table
```bash
# edit backend/app/models/__init__.py
cd backend && uv run alembic revision --autogenerate -m "add x"
# open alembic/versions/000N_*.py: delete any create_index/drop_index lines for *_location gist (auto-created)
uv run alembic upgrade head && uv run pytest -q
```

### Add a booking status
`BookingStatus` (models) → `ALLOWED` + actor sets (`services/lifecycle.py`) → `kStatuses` + `statusLabel` +
ARB keys `status_<name>` (mobile) → `STATUS` colours (`admin/src/components/ui.tsx`) → `STATUSES` filter list
(`admin/src/app/bookings/page.tsx`) → tests.

### Add/modify UI text in the app
Edit `mobile/lib/l10n/app_en.arb`, `app_hi.arb`, `app_mr.arb` (same keys) → `flutter gen-l10n` →
use `t.key` where `t = AppLocalizations.of(context)!`.

### Add an admin page
Create `admin/src/app/<route>/page.tsx` as an async server component using `apiFetch`; add to `NAV` in
`layout.tsx`. Client interactivity → small `"use client"` component under `src/components/`.

### Re-seed
```bash
cd backend
docker compose -f ../docker-compose.yml exec -T db psql -U gig -d gig -q -c \
 "TRUNCATE cooperatives, users, services, skills, worker_skills, workers, worker_certifications, customers, bookings, ratings, invoices, demand_history, forecasts RESTART IDENTITY CASCADE;"
uv run python seed.py
```
Then in the admin, **AI Forecast → Run 7-day forecast** (the seed does not run it).

### Reset the dev DB completely
```bash
docker compose -f ../docker-compose.yml exec -T db psql -U gig -d gig -c "DROP SCHEMA public CASCADE; CREATE SCHEMA public; CREATE EXTENSION postgis;"
cd backend && uv run alembic upgrade head && uv run python seed.py
```

## Troubleshooting

| Symptom | Cause / fix |
|---|---|
| `psql: server closed the connection unexpectedly` or tests can't connect | Something else owns 5432; we use **5433**. Check `lsof -iTCP:5433`. |
| `Cannot connect to the Docker daemon` | `open -a Docker`, wait for `docker info` to succeed. |
| `DuplicateTable: relation "idx_workers_location" already exists` on migrate | Autogenerated GIST index ops duplicate GeoAlchemy2's; delete them from the migration. |
| `xgboost … Library not loaded: libomp.dylib` | `brew install libomp`. |
| Flutter: `Target of URI doesn't exist: package:flutter_gen/...` | Import `package:mobile/l10n/app_localizations.dart`; run `flutter gen-l10n`. |
| Flutter: `setState() callback argument returned a Future` | Use a block body `setState(() { x = _load(); })`. |
| Flutter list doesn't update after an action | Same cause as above — the future was never assigned. |
| `Failed to bind web development server … port 5555` | `lsof -tiTCP:5555 -sTCP:LISTEN \| xargs kill -9`. |
| Admin renders dark cards with black text | `globals.css` must stay light-only (no `prefers-color-scheme` block). |
| Admin `apiFetch` throws `401` after ~15 min | Access token expired; sign out/in. Refresh flow is deliberately absent. |
| `POST /payments/demo-mark-paid` → 404 | `DEMO_MARK_PAID=false` in env; intended for production. |
| Match returns `[]` | No available worker with that service's skill within 10 km of the pin, or all busy at that hour. Default pin is Andheri where the seed guarantees plumbers/electricians/cleaners. |
| Forecast page empty | Run it once: **Run 7-day forecast** or `POST /admin/forecast/run`. |
| Claude browser pane can't screenshot | The pane is hidden; bring it to front, or use `read_page`/`get_page_text` (Flutter needs the "Enable accessibility" button clicked first). |

## Project conventions summary

- Commits: `feat(scope): …`, `fix(scope): …`, `docs: …`; one task per commit; `Co-Authored-By` trailer when an agent authored it.
- Branches: `main` is integration; feature branches optional (`backend` exists historically).
- Formatting: Python defaults (no formatter configured — keep lines ≲ 130), Prettier defaults for TS, `dart format`.
- Comments: sparse; `# ponytail:` / `// ponytail:` marks a deliberate shortcut with its upgrade path.
