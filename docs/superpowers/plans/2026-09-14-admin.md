# Admin Dashboard Implementation Plan (Plan 2 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Next.js federation admin consuming the FastAPI `/admin/*` endpoints: dashboard (tiles, demand map, forecast panel), Workers, Customers, Bookings, Cooperatives, Services, Payments, Welfare, Forecast.

**Architecture:** Next.js App Router, TypeScript, Tailwind. Login stores admin JWT in an httpOnly cookie via a route handler; server components fetch from FastAPI with that cookie's token. Leaflet (react-leaflet) for the demand map as a client component. Forecast bars are plain CSS.

**Tech Stack:** next@15, react, tailwind, react-leaflet + leaflet.

**Spec:** `docs/superpowers/specs/2026-09-14-coop-gig-platform-design.md` §Admin

## Global Constraints
- API base from `NEXT_PUBLIC_API_URL` (default `http://localhost:8000/api/v1`).
- Cookie `token` httpOnly; `middleware.ts` redirects unauthenticated to `/login`.
- No shadcn; small shared `ui.tsx` (Card, Table, Badge). Skipped: charts lib, state lib.

## File structure
```

  src/components/{ui,DemandMap,ForecastBars,RunForecastButton}.tsx

```
