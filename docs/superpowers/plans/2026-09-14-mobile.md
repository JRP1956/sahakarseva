# Mobile App Implementation Plan (Plan 3 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One Flutter app; role from JWT. Customer: browse services → book (map pin, schedule, emergency) → pick from matched workers → pay → rate. Worker: job requests with estimated earnings → accept/start/complete → earnings → availability, skills, certifications, welfare. EN/HI/MR.

**Architecture:** `Api` singleton (http + shared_preferences token), plain `StatefulWidget` + `FutureBuilder`; no state-management lib. `flutter_map` (OSM tiles) for pin picking. Localization via Flutter's gen-l10n ARB files.

**Tech Stack:** Flutter 3.47, http, shared_preferences, flutter_map, latlong2, intl, flutter_localizations.

**Spec:** `docs/superpowers/specs/2026-09-14-coop-gig-platform-design.md` §Mobile app

## Global Constraints
- API base `--dart-define=API_URL` default `http://localhost:8000/api/v1`.
- Verified on Chrome at 390×844; Android/iOS builds are deferred until toolchains exist.
- Razorpay SDK deferred (no web support); "Pay" calls `/payments/demo-mark-paid`.
